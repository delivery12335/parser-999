# 999.md Apartment Watcher

Асинхронный Telegram-бот на Python 3.12 для поиска публичных объявлений долгосрочной аренды на 999.md. В репозитории также находится Android-компаньон, который по одноразовой команде совершает обычный звонок через SIM-карту. Подмена Caller ID не используется.

## Для чего нужен

Проект помогает искать квартиру и следить за подходящими предложениями прямо в Telegram. Вместо регулярной ручной проверки сайта можно задать параметры аренды, получать карточки с фотографиями, сохранять варианты в избранное и переходить к звонку по доступному номеру. Сервер должен оставаться запущенным, чтобы фоновый мониторинг работал.

## Как работает

1. Пользователь взаимодействует с Telegram-ботом и задаёт фильтры поиска.
2. Парсер формирует URL поиска 999.md, загружает страницы выдачи и собирает ссылки на объявления.
3. Страницы объявлений загружаются с ограничением до четырёх параллельных запросов. Beautiful Soup извлекает цену, характеристики, описание, фотографии и публичный номер телефона.
4. Результаты проходят проверку фильтров. Бот отправляет подходящие объявления в Telegram, а база хранит настройки, избранное и историю отправок для защиты от дублей.
5. Фоновый мониторинг повторяет проверку с интервалом `CHECK_INTERVAL`. По кнопке звонка бот отправляет контакт для iPhone или создаёт одноразовую команду Android-компаньону — в зависимости от `CALL_MODE`.

```text
999.md → HTTPX + Beautiful Soup → фильтры → Telegram
                                      ↕
                              SQLAlchemy + SQLite
                                      ↕
                           FastAPI → Android → SIM
```

Основной стек: Python, aiogram, HTTPX, Beautiful Soup, SQLAlchemy и FastAPI. Android-приложение написано на Kotlin и опрашивает очередь команд каждые 5 секунд.

## Возможности

- районы, несколько вариантов комнат, автор, цена и валюта;
- дополнительные фильтры: площадь, этаж, мебель, техника, кондиционер, интернет и тип жилого фонда;
- первое фото в карточке и остальные фото альбомами;
- временное скачивание фото, если Telegram не может получить URL самостоятельно;
- фоновый мониторинг, история отправок и защита от дублей;
- избранное;
- закрытая одноразовая очередь звонков; первый пользователь новой БД становится владельцем;
- режим iPhone: нативная Telegram-карточка контакта и подтверждённый пользователем SIM-звонок;
- Android foreground service с HTTPS и Bearer-токеном.

Парсер работает только с общедоступным HTML. Он не обходит CAPTCHA, Cloudflare, авторизацию и другие ограничения. Официальный partners API 999.md требует отдельный API-ключ и предназначен прежде всего для собственных объявлений, поэтому здесь он не используется.

## Структура

```text
app/
  api/                 API очереди команд для Android
  bot/                 handlers, keyboards, FSM, карточки
  database/            SQLAlchemy-модели и repository
  parser/              ListingParser, модели, фильтры, selectors.py
  services/            поиск, мониторинг, фото, звонки
  config.py
  main.py
android/                Android-компаньон (Kotlin)
```

## Запуск сервера и бота

1. Установите Python 3.12 и создайте окружение:

   ```powershell
   git clone https://github.com/delivery12335/parser-999.git
   cd parser-999
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` командой `Copy-Item .env.example .env`. Создайте бота через BotFather, заполните `BOT_TOKEN` и случайный `ANDROID_API_TOKEN` длиной не менее 32 символов. Например, токен можно сгенерировать командой `python -c "import secrets; print(secrets.token_urlsafe(48))"`. Первый пользователь, который взаимодействует с ботом при пустой базе, атомарно записывается владельцем. Поэтому сначала запустите бота и сразу сами отправьте `/start`.

3. Проверьте `SEARCH_URL`: по умолчанию в нём уже выбран тип «Сдаю помесячно». Районы, комнаты, автор и жилой фонд бот подставляет динамически. Идентификаторы фильтров на стороне сайта могут меняться; все они и CSS-селекторы собраны в `app/parser/selectors.py`.

4. Запустите:

   ```powershell
   python -m app.main
   ```

   Telegram использует long polling, поэтому webhook не нужен. HTTP API слушает `SERVER_HOST:SERVER_PORT`. Проверка: `GET /health`.

5. Для Android опубликуйте API через свой домен с валидным HTTPS-сертификатом. Например, поставьте Caddy или nginx перед локальным портом 8000. Не открывайте API по HTTP и не помещайте токен в URL.

## Настройки `.env`

| Переменная | Назначение / значение в примере |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота от BotFather |
| `CHECK_INTERVAL` | Интервал мониторинга в секундах: `300` |
| `DATABASE_URL` | База данных: `sqlite+aiosqlite:///apartments.db` |
| `ANDROID_API_TOKEN` | Секрет доступа к API Android, минимум 32 символа |
| `CALL_MODE` | `iphone` для карточки контакта или `android` для команды компаньону |
| `SERVER_HOST`, `SERVER_PORT` | Адрес и порт HTTP API: `0.0.0.0:8000` |
| `PUBLIC_BASE_URL` | Публичный HTTPS-адрес сервера |
| `SEARCH_URL` | Базовая страница поиска долгосрочной аренды |
| `REQUEST_TIMEOUT` | Тайм-аут HTTP-запроса в секундах: `20` |
| `PARSER_PAGES` | Количество страниц выдачи за поиск: `2` |
| `USER_AGENT` | Заголовок клиента для запросов к сайту |
| `LOG_LEVEL` | Уровень логирования: `INFO` |

Локальные `.env`, `apartments.db`, `.venv` и результаты сборки исключены через `.gitignore`. Для переноса настроек используйте `.env.example` без реальных токенов.

## Android-компаньон

1. Откройте папку `android` в Android Studio (JDK 17). Выполните Gradle Sync. При необходимости Android Studio предложит установить SDK 35. В проект включён Gradle Wrapper 8.9.
2. Подключите отдельный Android-телефон с SIM, соберите и установите debug APK кнопкой Run.
3. В приложении укажите публичный адрес сервера **с `https://`** и тот же `ANDROID_API_TOKEN` из `.env`.
4. Разрешите звонки и уведомления, нажмите «Сохранить и запустить». Исключите приложение из оптимизации батареи в системных настройках производителя телефона.
5. Оставьте SIM для исходящих вызовов выбранной по умолчанию. На dual-SIM устройстве Android может показать системный выбор SIM.

При `CALL_MODE=iphone` после нажатия «📞 Позвонить» бот отправляет нативную карточку контакта. Нажмите номер в ней и подтвердите системный SIM-звонок — iOS не разрешает приложению выполнить обычный вызов скрытно. Действие записывается в таблицу `calls` со статусом `presented`.

При `CALL_MODE=android` сервер вместо этого создаёт UUID-команду. Создать её может только первый зарегистрированный владелец. Android забирает команду один раз, валидирует молдавский номер, запускает системный `ACTION_CALL` и отправляет статус. На некоторых прошивках Android запрещает запуск экрана звонка из фона; тогда отключите ограничения батареи/фоновой активности для приложения. Это ограничение ОС нельзя безопасно обходить.

## API Android

- `GET /api/android/commands/next` — атомарно забрать следующую команду;
- `POST /api/android/commands/{request_id}/status` — `dialing`, `completed`, `failed` или `rejected`.

Оба маршрута требуют `Authorization: Bearer <ANDROID_API_TOKEN>`. Команда после выдачи меняет статус с `pending` на `claimed`, а завершённая команда повторно обновлена быть не может. В таблице `calls` сохраняются объявление, телефон, время и статус.

Статус Android `completed` означает, что удалось запустить системный экран звонка; он не подтверждает ответ абонента или завершение разговора.

## Эксплуатация

- Не уменьшайте `CHECK_INTERVAL` ниже разумного значения; конфигурация ограничивает его минимумом 30 секунд, рекомендуемое значение — 300.
- Если сайт вернул 403, 429 или страницу проверки, бот пропускает цикл. Не подключайте обход защиты.
- Телефон виден только когда он уже присутствует в публичном HTML. Бот не раскрывает скрытые номера и не выполняет защищённые XHR-запросы.
- SQLite подходит для одного процесса. Для нескольких реплик замените `DATABASE_URL` на async PostgreSQL URL и добавьте драйвер.
